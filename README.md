# 相册整理（PhotoSwipe）

一个以“先判断、后确认”为核心的 iPhone 相册整理工具。照片只在设备上处理；只有用户在批次审核页确认后，标记照片才会移到系统“最近删除”。

## 已实现功能

- 按 10 / 15 / 20 / 30 / 50 张组成稳定批次
- 左滑下一张、右滑上一张，也可使用底部按钮操作
- 垃圾桶只标记待删除，审核页可逐张取消标记
- 系统删除取消或失败时保留当前批次及所有选择
- 真正同步系统“收藏”状态
- 分享原始照片文件，不在主线程解码大图
- 支持 iCloud 照片下载进度、失败提示和重试
- 明确处理未授权、拒绝、受限、有限访问、空相册和整理完成状态
- 已完成批次和每批数量保存在本机，下次打开可继续整理
- VoiceOver 操作、动态字体和“减少动态效果”支持

## 使用方式

1. 用 Xcode 打开 `PhotoSwipe.xcodeproj`。
2. 选择开发团队和一台 iPhone。
3. 运行后阅读隐私说明，再选择允许访问全部或部分照片。
4. 逐张浏览并标记待删除照片。
5. 在每批最后一张继续向左滑，进入审核页。
6. 检查缩略图后提交删除，或保留整批继续。

删除后的照片位于系统“照片”App 的“最近删除”中，可在系统保留期内恢复。

## 运行要求

- iOS 17.0+
- Xcode 15.0+
- 建议使用真机验证照片授权、iCloud 原图和系统删除确认流程

## 建议验收场景

- 首次启动后拒绝权限，再从系统设置恢复
- 有限照片权限下添加或移除可访问照片
- 31 张照片按每批 15 张完成三批整理
- 删除确认时点取消，确认选择仍完整保留
- 部分删除、整批删除、整批保留和最后不足一批
- iCloud 原图尚未下载时查看与分享
- VoiceOver、最大动态字体和“减少动态效果”模式
